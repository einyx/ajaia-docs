Welcome to Ajaia Docs

Ajaia Docs is a deliberately small collaborative editor: one focused slice of the Google Docs surface, built end to end — editor, persistence, sharing and deployment.

What works today

  • Rich text with bold, italic, underline, headings, lists and block quotes.
  • Autosave — every keystroke is persisted, so a refresh never loses work.
  • File import from .md, .txt and .docx.
  • Sharing with an owner, an editor and a viewer role.
Everything in this demo is mocked auth on purpose — see the README for the exact model.
